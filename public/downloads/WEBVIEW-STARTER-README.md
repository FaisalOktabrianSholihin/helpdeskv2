# Dua Tujuh Helpdesk - Android WebView Starter

Starter Android Studio project untuk membungkus website Helpdesk menjadi aplikasi WebView.

## Yang perlu diubah
Buka `app/src/main/java/com/mitratani/helpdesk/MainActivity.kt` lalu ganti:
`https://YOUR-HELPDESK-DOMAIN/`
menjadi URL Helpdesk yang sudah di-hosting.

Gunakan HTTPS untuk produksi.
